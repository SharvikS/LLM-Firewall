## Release Policy

Required before an enterprise release:

- `security-scan` workflow green.
- `release-gates` workflow green.
- Any high/critical Python or Go finding must be fixed, upgraded around, or
  documented with exploitability, compensating controls, owner, and review date.
- Any accepted vulnerability must have an explicit expiration/re-review date.
